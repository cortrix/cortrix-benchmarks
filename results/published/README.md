# Published Results

This directory contains only curated, approved benchmark result summaries. Raw runs, datasets, logs, and local diagnostic outputs must remain outside Git.

## Available bundles

- [Three-dataset full-corpus retrieval measurements](beir-three-full-corpus-2026-07-v1/README.md) (`beir-three-full-corpus-2026-07`): retrieval-quality-only results for SciFact, FiQA, and NFCorpus.

Each bundle carries its own manifest, scorecards, profiles, reproduction instructions, and checksum inventory. Cite a bundle through a 40-character commit-pinned URL and verify `checksums.sha256` before reuse.
